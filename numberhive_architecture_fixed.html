Number Hive · Business Model
Everyone plays. Admins pay to see.
Two roles, one gate. Players play free; Admins run hives and pay to reveal their hive's data. Teachers are the business; Hive Clash is the lean viral front door.
Play free→ Run a hive free→ Data accrues blurred→ Pay → reveal
The whole modelTwo roleseverything else is a flavour of these
🎮 Player
The universal account
  • Adults roam free — game, Hive Clash, account-level Hive IQ
  • Minors are contained under an Admin umbrella — provisioned, not roaming
  • Anonymous instant-play needs no account — the magic hook
🗝️ Admin
Anyone who runs a hive — teacher · parent · tutor · school
  • Provisions members, controls features (e.g. Hive Clash toggle)
  • Free Admin = full product, data hidden
  • Paid Admin = data revealed (one switch per hive)
How it convertsOne gatea single switch per hive
🎮 Free — everyone plays
Acquisition engine · no account needed to start
  • The game · Play a Friend · Hive Clash (free-to-play)
  • Representations + number-fact delight
  • Basic personal stats (comfort heat map is paid)
🔒
THE GATE
An Admin runs a hive free; members play; data accrues blurred. Pay → the blur lifts. One boolean per hive — never gates play.
🗝️ Paid Admin — data revealed
Single $0.99 · Group $4.99 · Class $7.99 · School (umbrella)
  • The Hive Vault — Buzz efficacy + mindset reports
  • Per-member & cohort fluency, heat maps, growth
  • Assign skills · competitions · export · (School: sub-admins)
Billing (PWA · Stripe — no app-store cut): per-hive, monthly or annual; lapse re-blurs but retains the data (hive goes Inactive, play stays free). Seat count is a price bracket, not a play cap — 41 students = two Class hives. Single = one admin + one learner (incl. an adult studying themselves) — the individual-analytics rung. School = a super-admin dashboard over all the school's teachers (replaces the promo-code).

The wildcard, handledHive Clash — lean viral front door
Free-to-play ranked (ELO = account-level Hive IQ, no chat, safe handles), monetised by cosmetics & seasons — never pay-to-win. One shared pool; admins toggle access, never the rating. Seeded by single-player so it's never a ghost town.

Run it lean — the viral front door of a teacher-first business, not a second company. Tripwire to scale B2C: invest in seasons/live-ops only once organic ranked retention + viral coefficient cross a pre-agreed bar.

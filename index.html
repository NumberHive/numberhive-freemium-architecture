Player Free Play User (B2C)
1. Lands on numberhive.app
2. Clicks "I want to play"
3. Chooses "Just play" (no code)
4. Enters name → jumps into game
5. Plays (data collected)
6. After first session: "Save progress?" → Optional email
7. Lands on Free Play Dashboard
🔒 Gated
Sees: Play a Friend, Practice vs BOT, Buzz Practice, Partial Gym Stats
8. Can invite friends (viral loop)
→ Conversion
Eventually: Joins hive or becomes teacher
Player Invited via Link
1. Receives: numberhive.app/invite/jamie456
2. Clicks link (no account needed)
3. Enters name → immediately plays vs Jamie
4. Game completes
5. Lands on Free Play Dashboard
✓ Network Effect
Now can invite others → exponential growth
Student In Teacher's Hive
1. Teacher shares code (NS7945) or link
2. Student clicks, enters code, enters name
3. Joins teacher's hive
4. Full gameplay experience:
• Hive Gym
• Learning Journeys
• Competitions
5. Can rejoin with: Hive code + name
✓ Data Persists
Teacher sees all data (if subscribed)
